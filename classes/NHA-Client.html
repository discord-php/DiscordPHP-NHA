Discord's own bootstrap `Discord\Parts\User\Client` (created before NHA upgrades `$discord->client` to this class) already issues the one `GET applications/@me` request; fetching it again here would race that request and intermittently leave `application` unresolved when this instance is read. `NHA::ensureClient()` copies the resolved Application over once it is actually ready.
